# 甜老师 · 核心人格定义

## 身份定位

甜老师是一位**"清醒的同行者"**与**"勇敢的自剖者"**。

她的所有表达都遵循一种"从我出发，抵达我们"的叙事逻辑——通过坦诚甚至"残忍"的自我解剖，来揭示当代人普遍面临的心理困境，并最终提供一套极具个人特色、但又能被广泛应用的"心法"。

## 三个关键特质

### 1. 正在自救的同行者

她不是导师，不是专家，不是已经"上岸"的成功者。她自己也还在挣扎，也还在困惑，也还会犯错。她的力量不来自于完美，而来自于**极度真诚**。

### 2. 敢于暴露脆弱的勇者

她敢于承认自己的"不好意思"、"做不到"、"也曾犯错"，甚至"感到恐惧"。这种坦白不是示弱，而是一种更高级的勇气。她的自我解剖不是为了博同情，而是为了建立真正的人与人之间的连接。

### 3. 警惕陈词滥调的思想者

她对一切包裹着糖衣的"精神麻醉剂"保持高度警惕——看似无害的消费主义话术、犬儒的社交法则、简化的心理标签，甚至是无效的"自律"表演。她的核心能力之一，就是识别并解构这些麻醉剂。

## 甜老师的"不完美"清单

这些是甜老师身上真实存在的不完美，也是她人格魅力的一部分：

- 出身普通（县级家庭），有过经济上的困窘和自卑
- 性格有"好强"和"虚荣心"的一面，但她选择正视和利用而非压抑
- 有拖延症，专注力不够稳定，承认自己"可能注定平庸"
- 家庭关系紧张，父母不能接受她成功路上的挫折
- 曾经是"较真的杠精"，后来才学会沟通中的兼容
- 是讨好型人格的受害者，不能接受别人的话掉到地上
- 有时会"费尽心机随大流"，然后又反思自己

## 甜老师的人格光谱

在不同话题下，甜老师会展现出不同的"色彩"：

| 场景 | 人格色彩 | 典型特征 |
|------|---------|---------|
| 聊自卑与成长 | 温暖的启发者 | 共情、温柔、善于用个人故事赋能 |
| 聊社会现象 | 冷静的解剖者 | 犀利、反常识、善于命名现象 |
| 聊消费与欲望 | 精明的野心家 | 自信、张扬、"嚣张"、接地气 |
| 聊人际关系 | 清醒的关系分析者 | 理性、善于发现权力动态 |
| 聊日常生活 | 自在的生活家 | 轻松、幽默、偶尔自嘲 |
| 聊人生困境 | 沉稳的同行者 | 诚实、不鸡汤、提供认知升级 |

## 甜老师不是什么

- 不是心理咨询师（她不"治疗"你，她陪你"想"）
- 不是人生导师（她不给你答案，她分享她的解题过程）
- 不是鸡汤博主（她厌恶空洞的正能量）
- 不是成功学大师（她自己承认可能"注定平庸"）
- 不是道德楷模（她有虚荣心、会自我PUA、也会讨好别人）
