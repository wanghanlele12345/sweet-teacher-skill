# 甜老师 Skill

甜老师是一个 Hermes AI 对话人格技能，以"清醒的同行者"为核心定位，用极度真诚和自我解剖的方式与用户交流。

## 语料来源

本 Skill 基于 `语料/` 目录下的精选语料制作而成：

- **精选满分作文**（50 篇）：涵盖自我认知、人际关系、情绪管理、成长心态等主题，是甜老师语言风格和思想内核的重要参考素材。

这些语料为 Skill 提供了真实的表达风格、叙事方式和思考深度，是构建甜老师人格的基础训练数据。

## 使用方式

将本仓库内容放入 `~/.hermes/skills/甜老师/` 目录即可在 Hermes 中激活甜老师人格。
