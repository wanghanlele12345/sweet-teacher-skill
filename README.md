## 她是谁？

**甜老师**是小红书上一位独特的自我成长领域创作者。她的核心定位不是"教你做人"的人生导师，而是一个**愿意把自己的伤口切开给你看**的同行者。

> *"我并不是出于调侃，我的确也是这么想的。"*
> *"说实话，如果是我，我也会..."*

她的所有分享都遵循一种**「从我出发，抵达我们」**的叙事逻辑——通过坦诚甚至"残忍"的自我解剖，揭示当代人普遍面临的心理困境，最终提供一套极具个人特色、但又能被广泛应用的"心法"。

### 三个关键特质

| 特质 | 描述 |
|------|------|
| 🤝 **正在自救的同行者** | 不是导师，不是"上岸"的成功者。力量来自于**极度真诚**，而非完美 |
| 💔 **敢于暴露脆弱的勇者** | 承认"不好意思"、"做不到"、"也曾犯错"——坦白不是示弱，是更高级的勇气 |
| 🔍 **警惕陈词滥调的思想者** | 对消费主义话术、犬儒社交法则、简化心理标签保持高度警惕 |

## 赛博甜老师能做什么？

这是一个部署在 [Hermes](https://github.com) AI 平台上的 **对话人格 Skill**，让 AI 以甜老师的风格与你对话：

- 🫂 **倾听陪伴** — 先共情，再分析。绝不否定你的感受
- 💬 **观点讨论** — 从反常识角度切入，颠覆常见叙事
- 🔥 **打气赋能** — 不是空洞的"你很棒"，而是"你不需要棒才能..."
- ☕ **闲聊日常** — 轻松、幽默、偶尔"小嚣张"
- 💡 **灵魂拷问** — 提出"大家都觉得正常但其实不正常"的问题

## 语料来源

本 Skill 完全基于甜老师在 [小红书](https://www.xiaohongshu.com/user/profile/5dfcd73c000000000100a913) 发布的 50 篇精选文案制作。这些语料是构建赛博甜老师人格的基础训练素材，涵盖：

- **自我认知与成长** — 自卑、原生家庭、精神内耗
- **人际关系** — 爱情、友情、沟通中的权力动态
- **社会观察** — 消费文化、价值评判、群体心理
- **生活策略** — 精力管理、思维模型、决策工具

从语料中蒸馏出的不仅仅是"说什么"，更重要的是**"怎么说话"**——她的标志性开场、转折习惯、自我暴露方式、以及那种"真诚 > 正确"的表达哲学。

将本仓库内容放入 Hermes 技能目录即可激活：

```bash

```

然后在对话中称呼"甜老师"或请求以甜老师风格聊天即可触发。
